- **2026-08-07** — [#187](https://github.com/msdixon/secret-cabinet/issues/187) closed, first of the two voices-thread items: a member's own library excerpt now feeds their speaker prompt as a voice-register exemplar. The #35a library's text had until now been read only by citation verification (#36/#153) — never by the member whose prose it is — so every voice rested on its character file's *description* of a register rather than on evidence of one. `buildSpeakerSystemPrompt` injects a trimmed slice under `## HOW YOU ACTUALLY WRITE — A PAGE IN YOUR OWN HAND`, placed after the character file (it is evidence for what that file describes) and before #188's disposition (which is about tonight and wants to be read last), framed narrowly as cadence and not subject — *"govern **how** you speak tonight, never **what**"*, plus an explicit do-not-quote/cite/allude instruction and a note that this is written prose being carried into speech. **The correctness decision worth knowing about:** lookup is keyed on a new explicit `author` field in `library.json`, deliberately *not* on the existing `members` array. `members` is an association list naming everyone an entry concerns — Waite's 1911 preface lists `pixie`, Jung's 1916 text lists `corbin` — so matching on it would have handed Pamela Colman Smith A.E. Waite's prose under the heading "how you actually write", a fabricated voice of exactly the kind this project's citation work exists to prevent. Consequence: **exemplar coverage is 21 of 33 members, not the 23 that library coverage reports** — the 2026-08-07 entry below counts a member as covered if they appear in any entry's `members`, which is the right measure for the graph and citation matching and the wrong one here. Twelve degrade gracefully (no section, voice-doc description alone, prompt byte-identical to before): the ten genuine hard passes plus Pixie and Corbin. A second new field, `translated`, marks the 12 entries whose English is a translator's rather than the author's, so those members are told to take the cadence and structure but not the diction — otherwise Teresa inherits E. Allison Peers's vocabulary as her own. Set by reading each citation rather than grepping for "trans.": Moina Mathers's 1926 preface is her own English, and the "trans." in its citation is S.L. MacGregor Mathers translating the book she was prefacing. 300-word budget trimmed on paragraph → sentence → word boundaries (a cut mid-clause reads to the model as a stylistic habit); 16 of 21 entries fit whole, and it bites only on Moina Mathers 584 words, Porete 434, Dion Fortune 406, Lévi 302, Hildegard 301. New `test/library.test.js` is an offline CI check on the index itself — every entry needs a roster-valid `author` that also appears in `members`, a boolean `translated`, one entry per author, and a non-empty body — because the failure mode is silent: a wrong `author` doesn't throw, it misattributes prose, the same class of failure #157 found in `source_url`. 214 tests, up from 184. - **2026-08-07** — [#185](https://github.com/msdixon/secret-cabinet/issues/185) closed: casting inverted, second of the three defaults-inversion items. Two mechanisms replace the cold open of 33 unselected tokens and a "0 present" badge, and neither removes hand-casting — Rachel's call that keeping favourites is a feature, not a bug to design out, is the load-bearing constraint here rather than a caveat on it. **Regulars:** a ✦ pin per member token marks someone always-invited, persisted in `localStorage` (`sc-regulars`) and seated on page load; regulars sort to the front of the grid and are marked there, and a regular who has since left the roster is dropped rather than carried forever. The pin sits inside the token but answers a different question — who is *always* here, not who is here *tonight* — so it stops propagation instead of also toggling presence. **The proposal:** when a document lands, one pre-convene call asks the director who *that document* would draw, with the regulars handed over as fixed input ("already coming, not yours to choose and not yours to drop") rather than as a suggestion the model may drop; it renders as a one-click accept and applies nothing until accepted. - **2026-08-07** — Two process bugs found and fixed while cleaning up after PR #199, both of which had been silently costing sessions time. **(1) The `post-checkout` hook never fires for the worktrees this project actually creates.** It works for a manual `git worktree add`, but Claude Code's harness creates worktrees without a checkout step, and `post-checkout` only runs on a checkout — verified by reproducing the exact reflog signature with `git worktree add --no-checkout` (a lone branch-creation line, no `reset: moving to HEAD`, identical to `.git/worktrees/*/logs/HEAD` for every harness-made worktree). That is why the silent-`babylonjs` failure kept recurring despite the hook existing since 2026-08-03; two live worktrees were sitting without `node_modules` when this was found. Fixed with a `predev` script in `package.json` (`npm install --no-audit --no-fund`, idempotent, ~1s) so `npm run dev` no longer depends on any hook firing; CLAUDE.md's Dependencies section rewritten to say so and to stop claiming the hook covers `git worktree add` in practice. **(2) `git merge-base --is-ancestor` is the wrong merged-check for this repo,** which squash-merges — a squash-merged branch is never an ancestor of `main`, so the heuristic CLAUDE.md prescribed reported "not merged" for work that shipped weeks ago. It gave false negatives on 6 of 12 worktrees in this pass, all of which would have been preserved as "active work"; `gh pr list --head <branch> --state all` is authoritative and is now what CLAUDE.md tells sessions to use (plus the `-D`-not-`-d` note for deleting such branches). Cleanup itself: worktrees 16 → 4, local branches 17 → 5, every removal confirmed merged against its PR first. Also fixed a red `main`: PRs #198 and #200 merged minutes apart tonight, #198 adding a test asserting the Witness end-of-replay hint text and #200 changing that text (`Click Exit…` → `← back · Exit to leave`), so neither CI run saw the other — assertion updated, suite back to 126/126.
