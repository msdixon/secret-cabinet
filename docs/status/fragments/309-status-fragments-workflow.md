STATUS.md moved to a fragment-based workflow: PRs drop a file in `docs/status/fragments/` instead of editing STATUS.md directly, and `scripts/assemble-status.js` (manual, or weekly via `.github/workflows/assemble-status.yml`) folds pending fragments into dated entries — the same pattern Towncrier/Changesets use to stop parallel branches from conflicting at STATUS.md's single insertion point. `.gitattributes` adds `STATUS.md merge=union` as a transition-period stopgap. This entry is itself the first fragment assembled under the new convention. [PR #309](https://github.com/msdixon/secret-cabinet/pull/309)
