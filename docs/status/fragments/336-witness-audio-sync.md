[#336](https://github.com/msdixon/secret-cabinet/issues/336): Witness auto-advance paced every beat off a fixed WPM guess even with voice on, cutting a long line off mid-sentence when the real utterance ran slower than the guess. `Voice.speak()` (`public/js/voice.js`) now returns a promise that resolves on the browser's actual `end`/`ended` completion event, and replay's `advance()` (`public/js/witness.js`) awaits it when something was actually spoken, falling back to the WPM estimate otherwise — a generation counter guards against a stale, late-resolving promise scheduling a phantom advance after the user goes back. 3 new tests, 752 total.
