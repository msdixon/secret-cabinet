[#29](https://github.com/msdixon/secret-cabinet/issues/29) second pass: an optional ElevenLabs backend for Witness voice playback, entirely gated behind `ELEVENLABS_API_KEY`. `src/routes/voice.js` proxies the TTS call and caches audio on disk keyed by voice+text so a replayed line is never re-synthesized or re-billed; `roster.js` backfills a deterministic `voiceId` per member the same hash scheme the Web Speech fallback already uses, but only once a key is configured, so an install with no key never gets `roster.json` touched. `voice.js` falls back to the untouched Web Speech path on any failure.
