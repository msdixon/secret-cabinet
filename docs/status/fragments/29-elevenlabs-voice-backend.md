[#29](https://github.com/msdixon/secret-cabinet/issues/29) second pass: an optional ElevenLabs backend for Witness voice playback, entirely gated behind `ELEVENLABS_API_KEY`. `src/routes/voice.js` proxies the TTS call and caches audio on disk keyed by voice+text so a replayed line is never re-synthesized or re-billed; `roster.js` backfills a deterministic `voiceId` per member the same hash scheme the Web Speech fallback already uses, but only once a key is configured, so an install with no key never gets `roster.json` touched. `voice.js` falls back to the untouched Web Speech path on any failure. Tested live against a real ElevenLabs account: the first version's `FALLBACK_VOICE_IDS` guess at ElevenLabs' legacy premade voices turned out mostly wrong (only 2 of 9 existed), fixed by replacing the pool with the account's real 21 voices, checked via `GET /v1/voices`; real synthesis, caching, and the full client pipeline all confirmed working end to end. Still open on #29: a real hand-authored voice/accent field, and tighter audio/text-reveal sync. 737 tests (added `test/voice-routes.test.js` and ElevenLabs-path coverage in `test/voice.test.js`).
