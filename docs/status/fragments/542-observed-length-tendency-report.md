[#542](https://github.com/msdixon/secret-cabinet/issues/542) (phase 2 of [#512](https://github.com/msdixon/secret-cabinet/issues/512)): added `scripts/report-observed-length-tendency.js`, an advisory-only report comparing each member's static `LENGTH_TENDENCY_OVERRIDES` entry against their observed average words-per-spoken-turn, gated at 20 real turns to avoid comparing on cold-start noise. Deliberately doesn't write back into `tuning.js` — the two design blockers #542 was filed against turned out resolved (#539's clarification that `LENGTH_WEIGHT` only affects speaker selection, not turn length; #506 shipping without depending on static tuning values), but cold start is real, so this stays a report a person reads rather than an auto-apply mechanism. When/whether to promote it is an open question, not decided here. [PR #573](https://github.com/msdixon/secret-cabinet/pull/573)
