"Show me a sitting" on the empty stage ([#623](https://github.com/msdixon/secret-cabinet/issues/623)) now replays a published past sitting on the stage itself (no API cost) instead of linking out to the reading room, with a "Convene your own variation" button that seats the sitting's room, puts its source text in the editable paste box and convenes live. The `sitting` id in `prompts/library/starters.json` is still null until a published session is chosen; generated starters stay deferred by design.
