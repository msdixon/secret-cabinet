Whether action text belongs outside the dialogue card (#291) and whether a third distinct text style is warranted both stay open for a future pass — no syntax currently distinguishes a genuine mid-sentence action aside from inline keyword text, so a mid-sentence aside will now be spoken too. 826 tests (2 updated, 2 added).
