Added a tracked `pre-commit` hook (`.githooks/pre-commit`) that runs `prettier --write` on staged `.js` files and re-stages the result, closing [#568](https://github.com/msdixon/secret-cabinet/issues/568)'s gap between drift and the CI gate `#544` hardened. Confirmed the hook fires in a harness-created worktree (unlike `post-checkout`, since `pre-commit` triggers on `git commit` itself rather than a checkout event) — but `core.hooksPath` resolves to an absolute path in the primary checkout, so the hook only goes live everywhere once this merges and that checkout runs `git pull`; see `CLAUDE.md`'s new "Pre-commit formatting hook" section.
