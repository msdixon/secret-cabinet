Brightened the 3D room ([#424](https://github.com/msdixon/secret-cabinet/issues/424), [PR #426](https://github.com/msdixon/secret-cabinet/pull/426)): sconces went from 3 bare marker-sphere lights to 6 fixtures with a wall-mounted backplate + cup, flush-mounted via the existing `wallSpot()` convention like the rest of the #304 dressing rather than floating independently, at higher intensity/range so the light pools visibly overlap. Ambient `HemisphericLight` nudged 0.5 → 0.62 as a shadowless general fill, leaving the hearth and sconces as the room's real light sources untouched. Stretch goal shipped too: a static lit candle at the table's center, its own short-range `PointLight`, deliberately not tied to the hearth's `fireLevel`. Verified live via before/after screenshots.
