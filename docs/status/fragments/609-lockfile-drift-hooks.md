Added a tracked `.githooks/post-merge` and a lockfile-changed check in `post-checkout` that run `npm install` when `package.json`/`package-lock.json` change, plus a `pretest` script mirroring `predev`, so the primary checkout's `node_modules` no longer drifts behind dependency bumps. Takes effect in the primary checkout once it pulls this; run `npm install` there once by hand. [#609](https://github.com/msdixon/secret-cabinet/issues/609)
