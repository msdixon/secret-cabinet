Fixed ElevenLabs TTS reading uniformly too slowly across every member ([#478](https://github.com/msdixon/secret-cabinet/issues/478)): `src/routes/voice.js` sent no `voice_settings.speed` at all, leaving pace at whatever ElevenLabs' bare per-voice default happened to be. Added `voice_settings: { speed: 1.1 }` to the request body, folding speed into the disk-cache key so the fix also reaches previously-cached lines rather than silently serving stale slow audio. The 1.1 default came from live A/B testing against the real ElevenLabs API (repeated trials to average out its own generation-to-generation timing variance) — consistently ~6-7% shorter audio than the 1.0/no-param baseline, comfortably inside the documented `[0.7, 1.2]` range.
