#330: `pickNextSpeaker`'s weighted draw now reads the director's priority order instead of discarding it — the pool from `selectSpeakers` was always ordered by relevance, but every candidate had equal odds regardless, so an obviously-relevant member (e.g. William Blake for a direct question) could go a whole passage without a turn. Each rank step down from the top now discounts draw weight (~2.4x top-vs-bottom in a 5-seat pool), stacking with the existing tendency/repeat/interrupt factors as one more weight, not a forced pick.
