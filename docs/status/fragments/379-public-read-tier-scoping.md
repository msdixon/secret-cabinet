Scoped the public read tier Rachel asked for — the app readable without login so it can be linked to friends remotely, with convening still gated ([#378](https://github.com/msdixon/secret-cabinet/issues/378), [#379](https://github.com/msdixon/secret-cabinet/issues/379), [#380](https://github.com/msdixon/secret-cabinet/issues/380)); a stranger lands on the room itself rather than a gallery, her call. The scoping's main finding was that the intuitive rule — "anything that doesn't hit an API is safe for a visitor" — covers cost and misses exposure: `GET /api/sessions` costs nothing and returns every stored session with journal-entry previews and full-text search, unfiltered by `published`. Promoted **Security to Principle 7** in `docs/PRINCIPLES.md` on its own stated trigger, which required the review to happen before the app is shown outside the one-person context rather than after.
