[#178](https://github.com/msdixon/secret-cabinet/issues/178) shipped: publishing a session to the reading room now opens a curation modal (a checkbox per passage, all checked by default) instead of publishing the whole transcript unconditionally, with a `publishedRounds` index array on the session record — absent/`null` still means every passage, so sessions published under #38's MVP render unchanged. An already-published session gets a new "Curate" action to revisit the selection without unpublishing, without bumping `publishedAt`. Adapted #178's original "rounds" proposal onto the #194 passage/lull data model — `session.rounds` never got renamed, so the index scheme reuses the same ordinal convention branching already keys off.
