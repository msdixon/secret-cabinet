[#452](https://github.com/msdixon/secret-cabinet/issues/452) shipped, closing out the reaction-portrait thread #449 opened: `scene.js`'s billboards now actually swap texture per member per #451's live `reaction` signal, via a new `applyReactionTexture` and `reactionTextures` cache mirroring the existing `portraitTextures` pattern. Falls back to the member's default portrait for `'none'` and for any member/reaction pair not yet generated (25/38 as of #470/#472) — waits for a confirmed successful load rather than optimistically assigning and correcting on error, since with most pairs currently missing that would flash blank on nearly every disposition update. Hard swap, not a cross-fade: Babylon has no built-in texture interpolation and the codebase had no cross-fade precedent to extend. Verified live against a real scene — a covered member's (Crowley) reaction image loaded and swapped, an uncovered member's (Jung) 404'd cleanly with the seat staying on their default portrait.
