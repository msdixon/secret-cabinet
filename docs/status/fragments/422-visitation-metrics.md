Visitation/traffic metrics for the public read tier (#379/#380), deliberately narrow: counts and logs unauthenticated requests to the app shell and public read-only API routes (`src/visits.js`), persisted to `visits.json` on `DATA_DIR` alongside a `GET /api/admin/visits` markdown summary behind the existing auth gate. No rate limiting, per-user auth, or alerting — just visibility, so the invite-only demo pool can be watched rather than assumed to stay small.
