Fixed [#477](https://github.com/msdixon/secret-cabinet/issues/477): `audio.playbackRate` was set once, at `<audio>`-element creation, so a mid-utterance speed-control click silently applied starting next beat only. `voice.js` now exposes `Voice.updateSpeed()`, called from `witness.js`'s `setSpeed()`, which reassigns `playbackRate` on whatever ElevenLabs clip is already playing — the Web Speech fallback is unchanged since `SpeechSynthesisUtterance.rate` can't be live-updated once speech starts. Verified live against the real ElevenLabs backend by cycling the actual speed button mid-utterance. [PR #490](https://github.com/msdixon/secret-cabinet/pull/490)
