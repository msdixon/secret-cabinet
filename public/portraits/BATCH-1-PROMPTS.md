# Batch 1 Portrait Prompts

Ready-to-paste generation prompts for the full current roster (33 members), per [STYLE_GUIDE.md](STYLE_GUIDE.md)'s Process step 1. Each entry is self-contained — the baseline register (tone, palette, composition, line quality) is restated in every prompt so nothing depends on external context once pasted into a generation tool.

Save each result as `public/portraits/<id>.png`, portrait-oriented, thumbnail-appropriate resolution (dossier-sidebar use only — see STYLE_GUIDE.md's Downstream use note; not yet verified for 3D-texture use).

**Likeness tier**, per STYLE_GUIDE.md's known-vs-unknown-likeness section:
- **Photographed** — aim for recognizable likeness against surviving photographs.
- **Character study** — no photographic ground truth; period-appropriate study, not likeness reproduction. Where the figure has an existing religious/devotional iconographic tradition, the prompt favors a secular framing over reproducing that iconography.

One flagged exception: **Amadou Bamba** has a single surviving photograph that is treated with particular reverence within the Muridiyya tradition (widely reproduced, near-devotional status). The prompt below aims for general recognizable likeness (dress, bearing, complexion) without directly reproducing that specific photograph's composition — worth your own judgment call on review, not something to generate on autopilot.
